No todos son imprescindibles para el MVP: los prioritarios bastan para una buena primera integración. Además, algunas tablas pequeñas de SAFFIRE, SLICE o ACME describen sesiones o condiciones experimentales y no contienen todas las mediciones físicas. No debemos sumar filas de diferentes tablas y presentarlas automáticamente como experimentos comparables.

Para conservar la integridad científica, recomiendo descargar los originales desde NASA PSI cuando sea posible y utilizar las copias enlazadas como referencia o alternativa, verificando que coincidan. La documentación oficial de NASA confirma la disponibilidad de estas familias de investigación.
